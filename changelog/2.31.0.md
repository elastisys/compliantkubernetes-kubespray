## v2.31.0-ck8s2

### "Security Notice(s)"

- This patch updates images to mitigate the [eMudhra intermediate CA compromise](https://emudhra.we-have-a-problem.com/).
- This vulnerability received a Welkin-specific CVSS 4.0 score of 9.1.

- Upgrade to Kubernetes v1.35.10
- Fixed components by patching images:
    - Kubernetes components
    - Etcd
    - CoreDNS
    - CSI components
    - Calico components
    - NGINX
